# MusicFinder 抖音取证助手（浏览器扩展）

在你 Windows 设备的 **Chrome / Edge** 里装这个扩展后，抖音取证任务会自动派到
你的真实浏览器里执行：真实浏览器指纹 + 家庭 IP + 滑块真人过——和本地抓取
效果一致，云端不再受数据中心 IP 风控影响。

## 安装（每台 Windows 设备一次，约 1 分钟）

1. 把整个 `extension` 文件夹拷到电脑上（或解压 extension.zip）
2. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择 `extension` 文件夹
5. 点浏览器右上角扩展图标的 🎵 图标，确认显示「✅ 云端连接正常」

之后保持浏览器开着就行：有人在云端提交抖音取证任务，你的浏览器会自动
弹出抖音搜索页、自动滚动抓取、完成后自动关闭。遇到滑块验证时**亲手滑一下**即可。

## 注意

- 抓取期间**不要手动关闭自动弹出的抖音标签页**（关了=放弃这单，云端自动转服务器抓取）
- 设备名建议按电脑命名（如 win-01、win-02），云端能看到哪台设备在接单
- 密钥找管理员（杨颖大王）要；扩展设置里可改云端地址

## 工作原理

扩展轮询云端领单 → 在你的浏览器打开 `douyin.com/search/...` → 拦截抖音
前端自动签名的搜索接口响应原文 → 回传云端解析入库（与服务端抓取同一套
解析和证据判定逻辑）。没有扩展在线时，云端自动回退 Xvfb 服务端抓取。
