Cookie & 登录态

配置各平台 Cookie 以获取更完整的数据（词曲作者、收藏量、评论数等需要登录态）

登录方式一 点各平台卡片里的「浏览器登录」按钮，会自动打开该平台登录页；登录后按 F12 复制 Cookie 粘贴保存。 · 登录方式二 自己获取：点「打开登录页」登录后，按 F12 复制 Cookie 粘贴保存（每台设备独立）。

手动获取 Cookie 的详细步骤（小白版）

  1. 在上面五张平台卡片里，点你想登录的平台卡片里的「打开登录页」按钮，会自动新开一个登录标签页
  2. 在那个新标签页里正常登录你的账号（密码、微信扫码、手机号都行）
  3. 登录成功后，按一下 F5 / 刷新一下当前页面，让浏览器把登录信息完整记录
  4. 按 F12 打开开发者工具 → 顶部切到 网络 / Network 标签
  5. 左侧请求列表里随便点一条（第一条就行），右边面板往下拉，在 Request Headers 区域里找一行 Cookie:
  6. 双击那行 Cookie: 后面那串字符让它全选 → Ctrl+C（Mac 是 ⌘+C）复制
  7. 回到这一页 → 粘贴到上方对应平台的输入框 → 点「保存 Cookie」
看不明白「Cookie 是啥」？打个比方：每条 Cookie 都是一张「我是登录用户 x」的小纸条，Cookie: 后面那串字符是一叠小纸条拼起来的长串，长得跟 p_skey=abc123; uin=12345; skey=xyz789; ... 类似。复制的应该是几百到几千字符、中间带 ; 的那种——不要复制成空的，也不要复制成单个字段。

自动不行？点平台卡片里的「浏览器登录」按钮是首选（密码登录会自动抓）。微信扫码、手机号验证码这俩方式自动抓不到（要跳到微信 app / 收短信，浏览器没法监听），请用上面手动步骤。

Cookie 会过期？对，一般几周就过期。届时再按这套步骤重新抓一次就行。

红心管理

登录各平台账号并抓取「我喜欢 / 收藏」歌单，搜索结果中自动打上对应平台红心徽章

红心 Cookie 独立存储 与「Cookie 设置」里的搜索登录态彼此分开，可分别配置不同账号。 · 推荐顺序 浏览器登录自动抓取 → 粘贴公开歌单链接 → 手动粘贴 Cookie → 手动粘贴歌单。

如何获取登录 Cookie？

  1. 用浏览器打开对应平台网页版（QQ：y.qq.com · 网易云：music.163.com · 酷狗：kugou.com · 酷我：kuwo.cn · 汽水：douyin.com）
  2. 登录你的账号
  3. 按 F12 打开开发者工具，切到 Network
  4. 刷新页面，点任意请求，在 Headers 里复制 Cookie 整行值
  5. 粘贴到上方对应平台卡片，点「保存 Cookie」后再「登录并抓取红心」
说明：QQ 音乐、网易云、酷我支持浏览器登录自动抓取 Cookie；酷狗可用「浏览器登录」或手动粘贴 Cookie；汽水因抖音接口签名保护，请用下方「歌单链接」方式导入。
